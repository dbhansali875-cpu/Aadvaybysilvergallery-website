AADVAY WEBSITE - FREE VERSION

This folder contains the AADVAY by Silver Gallery website.

To publish free with GitHub Pages:
1. Create a free GitHub account.
2. Create a PUBLIC repository called aadvay-website.
3. Upload index.html and the images folder.
4. Open Settings > Pages.
5. Choose Deploy from branch, select main, then Save.
6. GitHub will give you the live github.io address.

The website is designed for enquiries rather than online checkout.
